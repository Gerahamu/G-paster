# Windows v1.1.0 验证记录

## 实机

Windows 11 Pro x64，OS build 26200，单屏 2560 × 1600，系统缩放 165%。构建环境使用 Node.js 24.18.0 和 Electron 44.11.5。

- 通过 `npm run typecheck`、`npm run build` 和 unit suite。89 项中 88 项通过，0 项失败，1 项因 Windows 环境跳过符号链接试验。
- 选区脚本的程序级测试覆盖窗口预选、自由拖拽、移动、八向缩放、Esc 和选区动作直达。额外 2 项测试通过。混合 DPI、跨屏窗口裁剪和负坐标用独立几何单元测试验证。
- 从正式 NSIS 包按当前用户静默安装，核对已安装版本、桌面与开始菜单捷径、ASAR 和 WinRT OCR 辅助脚本。启动真实安装版，确认面板与截图快捷键在 Windows 注册成功。
- 使用已安装资源、真实原生托盘菜单、真实桌面截图和 Windows OCR 验证截图保存、识别复制、无文字反馈、取消、权限错误后的重试和截图成功提示。测试图和剪贴板测试使用隔离数据，复制目标为测试替身。
- 验证剪贴板图片、截图和图片常用语可按识别文字搜索，保存提示自动消失或随面板关闭清除，设置关闭后按偏好恢复页面，识别结果和修改过的快捷键跨进程重启保留，删除常用语后索引移除。
- 单元测试覆盖 OCR 暂时失败、索引写入失败、外部图片删除与文件重现。快捷键冲突分别检查应用自身和 Windows 全局绑定。
- 执行正式静默卸载，核对程序、快捷方式与卸载注册项移除。原用户记录未发生变化，原安装、注册信息、快捷方式和开机启动设置已恢复。

## 发布边界

- 单屏实测。物理多屏和混合 DPI、真实鼠标手势、受保护画面、锁屏和安全桌面未手动实测。权限拒绝通过注入错误验证；未改系统策略。
- Windows OCR 能力由机器已安装的语言决定。本次实机 OCR 使用英文样本。
- 单独的便携版在 Windows 构建成功，检查文件和 SHA-256。完整功能回归使用安装版。
- 安装包和便携版均未做 Authenticode 签名。`npm audit --omit=dev` 未报告生产依赖漏洞。完整审计仍报告 6 项构建依赖的中危发现。
