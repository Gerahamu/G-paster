# v0.1.6 发布验证记录

## 环境与范围

本轮环境：macOS 27.0.1、Apple Silicon arm64、Node.js 22.12.0、Electron 44.7.0。发布包为 macOS arm64 ZIP；安装包的最低系统版本元数据为 macOS 13.0，不表示所有 13.0 以上版本均已验证。

测试使用隔离数据、虚构记录和受控剪贴板输入。README 展示图取自同一测试界面，窗口按钮为示意，不包含用户剪贴板内容。没有更改现有用户数据或覆盖已安装应用。

## 此前专项测试证据

图片修复阶段曾从 Photo Booth 直接复制已有静态照片，确认剪贴板提供旧 Apple TIFF 与文件引用、没有标准 PNG。在隔离测试中模拟原图路径无法读取：旧版报错，新版成功使用 TIFF 数据生成有效 PNG。这确认了旧格式识别与备用路径问题，不能据此断言每台用户机器原始报错的具体权限原因。

## 未执行与能力边界

- Intel Mac、其他 macOS 版本、Windows 和 Linux 本轮未实机验证，也未提供预编译包。
- 完整多 Spaces、全屏应用、Stage Manager、多显示器组合仍需目标机器人工验证。
- 本轮未完整验证所有目标应用的跨应用粘贴及 Finder 拖放；受控接口写回 PNG 不等于全部系统粘贴场景通过。
- AirDrop/浏览器下载后的 Gatekeeper 首次安装、系统文件权限申请与实际注销/登录项启动未完成本轮独立机器验证。
- 没有执行 24 小时后台运行、长时内存/CPU 压测或所有复制速度组合。
- WebP / AVIF 虽已识别，实际编码夹具及多系统解码尚未覆盖。GIF 保存为静态 PNG；RAW、视频、不可用云端原图和只有失效文件引用的来源不保证导入。
- 图片默认共享池为 10 张，收藏不防自动淘汰，可在现有设置中修改上限。没有新增加密、敏感内容过滤或云同步。
- 仓库尚未添加开源许可证；本轮未替作者选择授权协议。

## 分发说明

发布资源为 `G-paster-v0.1.6-macos-arm64.zip` 和 `SHA256SUMS.txt`。更新时退出旧应用并替换 `.app`，保留应用数据目录。下载后用 `shasum -a 256 -c SHA256SUMS.txt` 检查完整性。

本次公开提供 macOS arm64 下载包，并保留以上验证边界。尚未验证的平台、系统权限与长期稳定性不标记为已通过。
